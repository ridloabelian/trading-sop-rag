*   **Aturan / Parameter Spesifik**: Tidak ada aturan teknis trading (indikator/timeframe). Video ini menjelaskan struktur manajemen dana pada broker HFM:
    *   **myHF ID (Wallet)**: Identitas utama klien (satu klien, satu ID). Berfungsi sebagai "rumah" untuk menampung dana deposit.
    *   **Akun Trading**: Sub-akun di bawah myHF ID (bisa memiliki banyak akun dengan tipe berbeda seperti Premium, Pro, Zero). Berfungsi sebagai "kamar" untuk melakukan transaksi trading.
    *   **Prosedur**: Dana harus didepositkan ke *Wallet* terlebih dahulu, kemudian ditransfer (*Transfer Funds*) ke *Akun Trading* agar bisa digunakan untuk bertransaksi.
*   **Poin Unik / Kutipan Penting**:
